# SIH Official Evaluation Benchmark Suite

This directory contains the reproducible evaluation suite for the **Privacy-Preserving Browser Vision Agent**, developed for the **Smart India Hackathon (SIH)**.

The suite provides empirical, measured evidence for the 5 official SIH evaluation criteria without fabricated metrics or simulated claims.

## How to Run the Evaluation Benchmark

### Option 1: Standalone Runner (Zero external setup)
```bash
node evaluation/benchmark_runner.js
```
This runs the full benchmark suite, prints the detailed breakdown for all 5 metrics, and updates `evaluation/results/sih_evaluation_report.json`.

### Option 2: Integrated Jest Test Suite
```bash
npm test -- --watchAll=false --ci --runInBand src/__tests__/sihEvaluation.test.ts
```
Or run the entire test suite:
```bash
npm test -- --watchAll=false --ci --runInBand
```

## Key Technical Disclosures & Accuracy

1. **Agent Engine Status**:
   - **Currently Active & Verified**: Deterministic structured action planner.
   - **Architectural / Optional**: Local neural VLM (`Qwen/Qwen2.5-VL-3B-Instruct` via `server/vlm/loader.py`). Model weights are not bundled by default; when hardware or weights are absent, system falls back to the deterministic action planner.
   - **Do not claim**: GPT-4o or a live neural VLM is running unless weights and GPU VRAM are explicitly loaded.

2. **Visual Context Metric (25%)**:
   - Visual context in the current prototype consists of the client-side **Accessibility Tree**, **Sanitized DOM Skeleton**, and **Canvas Visual Region Mapping**.
   - It is evaluated as structured screen state extraction fidelity rather than open-domain zero-shot computer vision classification.

3. **PII Detection Performance (20%)**:
   - High sensitivity is prioritized (100% recall on ground-truth sensitive items) to prevent privacy leaks.
   - Precision is 90.91% due to defensive matching on ambiguous numeric sequences (e.g., 8-digit tracking IDs matching phone formats).

4. **Fail-Closed Network Privacy Contract**:
   - If raw PII or an unredacted region is detected in an outgoing payload, transmission is blocked immediately with an error before hitting the network.
   - The FastAPI backend independently rejects any raw PII in metadata with `422 Unprocessable Entity (POLICY_VIOLATION)`.
   - Credentials referenced via `LOCAL_EMAIL` or `LOCAL_PASSWORD` are resolved strictly inside the local browser context and never transmitted to the server.
