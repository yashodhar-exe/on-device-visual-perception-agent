Privacy Firewall Test Page

Load this page with the extension active. It should automatically scan and draw colored overlays over every sensitive item below.

What the extension should do

  • Red overlay — Password field below
  • Blue overlay — Email address in the input and in plain text
  • Green overlay — Phone number
  • Purple overlay — Visa card number
  • Orange overlays — OpenAI key, GitHub token, Stripe key, JWT, DB URLs, AWS key
  • Red overlay — Social Security Number (Gov ID)

After overlays appear, click the extension icon in Chrome toolbar. The popup should show a Risk Score and list all detected items.

Login Form — Inputs

The extension detects typed values inside input and textarea fields.

API Key Input — Textarea

Detects secrets pasted into textareas.

Config Object — Firebase / Supabase

Detects config objects that contain embedded secrets.

const firebaseConfig = { apiKey: "AIzaSyABCDEF1234567890abcdefghij", authDomain: "myapp-12345.firebaseapp.com", databaseURL: "https://myapp-12345-default-rtdb.firebaseio.com", storageBucket: "myapp-12345.appspot.com" };

Plain Text — Embedded PII

Detects PII embedded in paragraphs and descriptions.
